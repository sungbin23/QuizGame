# 👑 지식왕 도전 Ultimate (Knowledge King Challenge)

Vanilla JavaScript로 개발된 웹 기반 상식 퀴즈 게임입니다. 생성형 AI 콘텐츠 작성 시 발생할 수 있는 **할루시네이션(Hallucination, 정보 오류)을 방지하는 교차 검증 가이드라인**을 적용하여 구현되었습니다.

## 🌟 주요 기능 및 특징
- **6개 카테고리 지원**: 한국사, 세계지리, 과학, IT/컴퓨터공학, 예술과 문화, 게임/서브컬처
- **4가지 다채로운 게임 모드**:
  - 🟢 **일반 모드**: 시간 제한 없이 여유롭게 풀기
  - ⚡ **스피드 퀴즈**: 문제당 15초 제한 타임어택
  - 💀 **서바이벌**: 오답 시 즉시 게임 오버
  - ⏱️ **60초 타임어택**: 60초 동안 최대한 많은 점수 획득
- **몰입감 넘치는 UX/UI**:
  - **Web Audio API**: 외부 음원 파일 없이 내장 신디사이저 기반 효과음 출력
  - **Canvas Confetti Engine**: 정답 및 최고 기록 달성 시 폭죽 연출
  - **오답 화면 흔들림 애니메이션**
- **기록 저장 기능**: 브라우저 `localStorage` 기반 역대 최고 점수 저장
- **자동화 검증 스크립트 제공**: `validate_quiz.py`를 실행하여 퀴즈 데이터 내 모호한 최상급 표현 자동 탐지

## 🛡️ AI 할루시네이션 방지 가이드라인 (Data Integrity)
본 프로젝트의 모든 퀴즈 데이터는 다음 기준을 엄격히 준수합니다.
1. **정답 유일성**: 유일한 정답만 존재하도록 질문 구조화
2. **최상급 표현의 기준 명시**: '가장', '최초' 등의 표현 사용 시 측정 기준(예: 2024년 기준, 전통적 기준) 명시
3. **교차 검증**: 다수의 신뢰할 수 있는 출처를 근거로 데이터 구성

## 🚀 실행 및 테스트 방법
1. 본 저장소를 클론합니다.
2. `index.html` 파일을 웹 브라우저(Chrome 등)에서 직접 열어 실행합니다.
3. 데이터 검증을 진행하려면 터미널에서 다음 명령어를 실행합니다.
